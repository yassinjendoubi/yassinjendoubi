## 🚀 Featured Projects

### 🔄 [FlowOps](https://github.com/yassinjendoubi/FlowOps)

FlowOps is an ASP.NET Core MVC application developed during my internship for monitoring and managing Windows Worker Services.

It allows administrators to start and stop services, monitor running processes, inspect live logs and service history, edit configurations, browse deployed service files, register new services, and track process IDs.

**Technologies:** ASP.NET Core MVC · .NET 8 · C# · HTML · CSS · JavaScript · JSON/JSONL · Windows Task Scheduler

---

### 🎓 ForME — [Backend](https://github.com/yassinjendoubi/ForMeBack) · [Frontend](https://github.com/yassinjendoubi/FormeFront)

ForME is an e-learning, professional training, and certification management platform developed as a final-year engineering project.

The platform includes authentication and role management, training programs, evaluations, certifications, administrative features, and a microservices-based architecture.

**Technologies:** Java · Spring Boot · Spring Security · JWT · Eureka · API Gateway · Angular · TypeScript · MySQL · Docker
