## 🚀 Featured Projects

### 🔄 [FlowOps](https://github.com/yassinjendoubi/FlowOps)

FlowOps is an ASP.NET Core MVC application developed during my internship for monitoring and managing Windows Worker Services.

It allows administrators to:

- Start and stop worker services
- Monitor running processes
- Inspect live logs and service history
- Edit service configurations
- Browse deployed service files
- Register new services
- Track process IDs

**Technologies:** ASP.NET Core MVC · .NET 8 · C# · HTML · CSS · JavaScript · JSON/JSONL · Windows Task Scheduler

### 🎓 ForME

ForME is an e-learning, professional training, and certification management platform developed as a final-year engineering project.

The platform includes:

- Authentication and role management
- Training program management
- Evaluations and certifications
- Administrative features
- Microservices-based architecture
- Service discovery and API Gateway
- Containerized deployment

**Technologies:** Java · Spring Boot · Spring Security · JWT · Eureka · API Gateway · Angular · TypeScript · MySQL · Docker
